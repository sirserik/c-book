# C++ с нуля

Учебник по C++ для русскоязычной аудитории. База — C++11, C++14/17 как бонус.

## Что внутри

Четыре полноценных консольных проекта по нарастанию сложности — учим язык, делая их:

1. **`demo-rpg/`** — текстовая RPG (Zork-стиль): локации, инвентарь, NPC, бои, сейвы.
2. **`demo-shell/`** — мини-bash: pipes, redirections, builtins, история, мини-утилиты.
3. **`demo-db/`** — мини-СУБД с B+tree, WAL и мини-SQL.
4. **`demo-chat/`** — TCP-мессенджер с многокомнатным чатом и event-loop сервером.

Содержимое книги — в `docs/tutorial/`, по одной главе на файл.

## Сборка PDF

```bash
$ bash build/build-pdf.sh
```

Требуется `pandoc` и `xelatex` (TeX Live). На macOS:

```bash
$ brew install pandoc
$ brew install --cask mactex   # или basictex для лёгкой версии
```

Скрипт сначала отдаёт markdown в pandoc, потом гонит xelatex три раза — чтобы оглавление, перекрёстные ссылки и номера страниц сошлись.
